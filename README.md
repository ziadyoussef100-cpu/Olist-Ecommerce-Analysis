# Olist E-Commerce Data Analysis Project

## Project Overview
This project focuses on analyzing the Brazilian Olist E-Commerce dataset to discover business insights and understand sales performance, customer distribution, product categories, payment methods, and seller performance.

## Project Objectives
- Analyze overall sales and revenue.
- Understand customer purchasing behavior.
- Identify top-performing product categories.
- Analyze payment methods and installment patterns.
- Explore geographic sales distribution across Brazil.
- Evaluate seller distribution and performance.

## Tools & Technologies
- SQL Server – Data extraction and querying.
- Python – Exploratory Data Analysis (EDA).
- Power BI – Interactive dashboards and data visualization.
- Excel & Power Query – Data cleaning and preparation.
